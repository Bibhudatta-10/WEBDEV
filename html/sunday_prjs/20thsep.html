WHAT I AM LEARNING

I am currently learning the fundamentals of web development, starting with HTML and CSS. During the first few days, I learned how to create the basic structure of a webpage using different HTML elements such as headings, paragraphs, links, images, sections, articles, forms, tables, and more. I also practiced creating different webpages and connecting them using anchor tags. After building a foundation in HTML, I started learning CSS in more detail. I have practiced different types of CSS, selectors, colors, spacing, borders, border-radius, Flexbox, gradients, hover effects, transitions, transforms, and page layouts. I am also learning how different CSS properties work together to control the appearance and arrangement of webpage elements. Instead of only learning the syntax, I am trying to practice each concept by building small projects. My current goal is to become comfortable with the fundamentals, improve through regular practice, and gradually move toward more advanced web development concepts.
